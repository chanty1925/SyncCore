# VISION DEL PROYECTO

SyncCore es un sistema de simulaciòn de bajo nivel diseñado para modelar el comportamiento de los planifacadores de procesos no apropiativos

First-Come, First-Served (FCFS)
Shortest Job First (SJF)
Asignacion de prioridades

y apropiativos como lo son el

Round Robin
Shortest Remaining Time First (SRTF)

Enfocado en analizar la funcionalidad de estos algortimos para el desarrolo del aprendizaje de sistemas Operativos. El uso de recursos de la CPU por parte de los procesos pueden llegar a generar problemas dentro del Sistema Operativo ocasionando problematicas como una latencia alta siendo una de las principales razones por la cual se desarrolla este simulador proporcionando un entorno de pruebas controlado para la evaluacion de la eficiencia de los algoritmos de planificacion con un desarrollo modular. Es necesario comparar estos algoritmos para el analisis de metricas de rendimiento de cada algoritmo utilizados en los Sistemas operativos y como estos pueden llegar a causar fallas por un algoritmo ineficiente causando problemas de iniciacion y el impacto del cambio de contexto en el rendimiento global del sistema
